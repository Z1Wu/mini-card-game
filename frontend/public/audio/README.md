# 对局音频

本项目作者于 2026-10-01 请求 Codex 为游戏原创编曲并用程序音频合成生成以下资源；未使用第三方录音、采样或音乐素材。项目作者可将这些资源随游戏使用、修改和分发。

- `horror-suspense-loop.wav`：64 秒循环恐怖悬疑背景音乐（试听 v2），低频持续音、失谐钟声、擦弦音色和不规则心跳；22.05 kHz、16-bit、双声道 PCM。由原 44.1 kHz 试听版降采样，减少下载体积。
- `card-play-dark.wav`：0.72 秒卡牌摩擦、落桌及低沉尾音；44.1 kHz、16-bit、双声道 PCM。

使用浏览器原生 WAV 播放以保持格式兼容。音乐音量为 30%，出牌音效为 65%。资源仅用于氛围反馈，声音开关同时控制二者，默认开启，偏好保存在本地。
