# 末世旧校舍美术

Issue #137。少女们在封闭旧校舍避难，一位同伴突然死亡且无醒目外伤。尸体防腐处理与寻找犯人同时进行。恐怖通过环境破败、物资短缺、疲惫和猜疑表现。

## 统一风格

- 全部13种角色均重绘为高中生少女，清晰线稿、平涂色块与赛璐璐硬边阴影。
- 制服统一为深灰蓝水手服、灰白双蓝线领口、暗酒红领巾及深灰百褶裙。发型、表情与职责用品区别身份。
- 外星人仍是原规则的卡牌角色名称，插画表现为受到猜疑的陌生少女；感染者表现为疲惫、口罩与绷带。没有魔法光效、异形身体或玄幻服饰。
- 废旧课桌带磨损、裂纹和水渍，边角放置旧纸张、纱布与医疗箱。中心保持可放置卡牌的清晰木面。
- 卡框、牌背与界面采用灰绿封存档案风格；所有隐藏角色使用同一牌背，不暴露身份。

## 素材

- `frontend/src/assets/art/cards/*-apocalypse-v1.webp`：13种角色插画。
- `frontend/src/assets/art/tabletop-apocalypse-v1.webp`：废旧桌面。
- `frontend/src/assets/styles/apocalypse-table.css`：卡框、牌背与配套样式。
- `docs/apocalypse-art-prompts.json`：内置 ImageGen 的最终逐素材提示词。

原始输出保留在 Codex 的 generated_images 目录，新素材转换为 WebP 后存入项目。旧素材保留，消费者引用新版本。此变更不改变角色能力、出牌规则、认证或服务端牌面可见性。
