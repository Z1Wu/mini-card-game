# 旧校舍卡面与回合 UI（Issue #141）

13 个角色保留不同发色、瞳色、制服年级领巾、动作和场景。内置 ImageGen 将血迹较多的旧版本编辑成柔和红调，生成统一的废弃教室牌背；旧素材保留。

- 卡面 `frontend/src/assets/art/cards/*-soft-red-v3.webp`：480×720，约 26–44 KB；图片铺满卡面，只留 2px 阵营边框。
- 桌面 `frontend/src/assets/art/tabletop-soft-red-v3.webp`：959×540，约 55 KB。
- 牌背 `frontend/src/assets/art/card-back-classroom-v1.webp`：红调废弃教室，中文白色楷体标题「冰冷的她醒来前」及英文斜体「Embalming Girl」由 DOM 叠加，避免生成文字不准确。
- 提示词保存于 `docs/soft-red-art-prompts.json` 和 `docs/card-back-prompt.json`。
- 卡名左侧竖排白字，底层黑色渐变保证对比度。右上白色手掌印配黑色调和值；右下白圆形配黑色罗马数字优先级。调和卡隐藏优先级，长按详情同样不展示它。
- 阵营只用细边框区分：学生灰绿、犯人/共犯暗红、感染者灰紫、外星人灰蓝、归宅部赭黄；移除年级框线，年级领巾仅保留在制服插画里。
- 手牌区域下方不使用红色蒙板。调和、质疑、特技按钮仅显示动作名，完整特技说明仍可通过卡牌详情查看。
- 公开场牌按玩家分区并堆叠，桌面露出每张左侧 26px、短横屏露出 20px，确保竖排名称可见；多牌可在各自区域横向滚动。桌面宽 84px，短横屏宽 64px。对手手牌只显示公开数量。
- `TurnAnnouncement` 根据游戏 ID、回合计数和当前玩家 ID 去重，初始回合也提示，2.2 秒后消失；快速切换重启计时，支持减少动态效果且不阻挡操作。
- `/fixtures/card-art` 支持 `width`、`harmony` 参数；`/fixtures/game-table` 支持 `players`、`fields`、`turns` 参数。
- 验证覆盖 59 项单元测试、lint、build；三种视口/三种人数的普通和八张场牌布局、堆叠名称可见性、13 张新卡面加载、40/48/96px 竖排名称与调和卡优先级隐藏，以及回合动画检查。E2E 手牌定位限定为 `.table-hand-scroll`，不把公开场牌当作手牌。

手牌右侧纵排调和、质疑、特技按钮；本地玩家只保留被质疑牌数量，调和状态固定在屏幕中央。左上角游戏记录直接打开服务端公开行动列表，调和/质疑不显示牌名，特技只显示已经公开的卡名和目标。

公开特技牌先在中央亮牌约1秒，再于0.5秒内飞入所属玩家场牌；入场前从场牌展示中暂时排除，只影响客户端显示。调和、质疑、特技分别播放舒缓上行音、低沉下行音和清脆三音；Web Audio 在本地首次点击/按键后启用，不补播历史。重复状态广播不会重复表现，减少动态效果模式保留静态亮牌并省略飞行。
